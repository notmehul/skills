# Assets visual taste (Mehul)

Source: Pinterest profile `skrr` / `probablymehul` (sampled Sep 2026) + cover iteration for memory-bench.

- Swiss/modernist editorial grids, technical diagrams, blueprints, cybernetics
- Brutalist + vaulted monumental architecture (sepia/gray, huge scale)
- Surrealism / weirdcore / occult-mythic (Indra's Net, mandalas, eyes, dragons)
- Retrofuturism + solarpunk future cities (`for the next people`)

- Tensed twin/difference friction when the claim needs it
- 1–2 options max; stop for pick; locked cover is final
- Grok Imagine only; use his refs + this skill as style anchors
