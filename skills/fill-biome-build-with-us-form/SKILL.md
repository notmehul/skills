# Fill Biome Build With Us form

Use signed-in Chrome on this computer. Destination: [https://www.biome.in/build-with-us](https://www.biome.in/build-with-us) (homepage [https://www.biome.in/](https://www.biome.in/) also has a **Build with us** nav link and hero button that go here).

This is the full-time application only. Internships and fellowships use the Biome Fellowship Program section on the same page — do not use this skill for those.

## Inputs

- `{willing_hyderabad}`: Yes or No — they do not offer remote; office is Hyderabad
- `{first_name}`, `{last_name}`
- `{linkedin}` — profile URL
- `{email}`, `{phone}`
- `{about}` — a little about yourself
- `{why_biome}` — why interested in working with Biome
- `{start_date}` — when they can start
- `{cv_url}` — link to CV/resume

If an input is missing, ask before filling. Do not invent personal details.

## Steps

1. Open https://www.biome.in/build-with-us
2. If a cookie banner appears at the bottom (**Decline** / **Allow Cookies**), dismiss it so it does not cover the form. Prefer **Decline** unless the user asked otherwise.
3. Scroll to **Work With Us**. If the section is collapsed, click the chevron next to the heading to expand it. Ignore **Build With Us** (founder/team path) and **Biome Fellowship Program**.
4. Answer **Are you willing to work out of our Hyderabad office?** with `{willing_hyderabad}` (radio **Yes** / **No**). Answering the radio reveals the rest of the form.
5. Fill the underlined fields:
   - First name / Last name
   - Linkedin
   - Email
   - Phone
   - Tell us a little about yourself
   - Tell us why you're interested in working with Biome
   - When can you start?
   - Please provide a link to your CV/Resume
6. **Stop before submitting.** Show the filled form and wait for an explicit yes before clicking submit/send. Never submit this application unprompted.

## Report

Say the URL, the Hyderabad answer, which fields were filled, and whether the form was submitted.

## Notes

- Assumes the box Chrome can load biome.in. No login is required for the public form.
- Dummy demo values like `abc xyz` / `xyz` must never be reused.
