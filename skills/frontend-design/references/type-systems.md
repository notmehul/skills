# Type systems by class

Forty-four free systems from Google Fonts and Fontshare, grouped by class, with the commercial faces each stands in for and the display settings that make it work. From taste-skill v2's library (MIT, read 18 Oct 2026), where each was seen on studied gallery sites. Use the class to choose, then pick a face that is not the one every generated page is using this season; check Fontshare licences per face before a client ships.
