# Directories and registries

Trimmed from the marketingskills `directory-submissions` list (September 2026) to the surfaces that fit developer tools, agent products, and Indian startups. Directories come and go, so open each one and confirm it's live and accepting submissions before you plan around it. Record the date you submitted and the listing URL.

## Launch platforms

| Where | Fit |
|---|---|
| Product Hunt | The broad launch-day event. Prep two to three weeks ahead; see the SKILL. |
| Hacker News (Show HN) | Only with a technical angle. Title: "Show HN: <product>, <what it does in plain words>". |
| DevHunt | Developer tools. |
| BetaList | Before launch, to build a waitlist. There's a queue unless you pay to expedite. |
| Indie Hackers | Build-in-public posts and a product directory. |

## MCP and agent registries

Only when the product exposes an MCP server or agent capabilities. These audiences are small but actively looking.

| Where | Notes |
|---|---|
| Official MCP Registry (modelcontextprotocol, Linux Foundation) | The canonical registry; you submit through its publishing flow. Check its current docs for the method. |
| Glama MCP directory | Grades servers on security; a good grade matters, so read its criteria first. |
| APITracker MCP directory | A curated list. |
| AI Agents List (aiagentslist.com) | Agent and MCP directory. |

## Software directories

| Where | Fit |
|---|---|
| AlternativeTo | List it as an alternative to the tools people already use. |
| SaaSHub | Ranks for "<tool> alternatives" searches. |
| StackShare | Developer-centric and stack-based. |
| Inc42 | Indian startup media plus a directory. |

## Adjacent

- "Best <category> tools" roundups: find them with `"best <category> tools" 2026` and pitch the author with a specific reason to include you.
- If an integration partner has a marketplace or an integrations page, get listed there.
