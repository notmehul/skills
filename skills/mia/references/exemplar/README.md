# Exemplar

A fictional deal, "Northlake", rendered in the sheet dialect. It exists to
show shape and density: how short a cell is, what a Read bullet looks like,
where a chart earns its place, how a matrix reads. Every company, person and
number in it is invented for that purpose.

Render it with `python3 skills/mia/scripts/render_sheet.py <workspace>` after
copying these files into `<workspace>/sheet/`, or run the test suite, which
does exactly that.
