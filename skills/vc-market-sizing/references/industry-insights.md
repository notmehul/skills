# Industry Insights (What to Pull, Where)

Use this to turn a market size number into an investor-grade narrative.

## What to Extract (Checklist)

- Spend drivers: what budget line funds this, how it scales, cyclicality
- Hard constraints: regulation, credentialing, supply limits, procurement cycles
- Market structure: fragmented vs concentrated; who has pricing power
- Incumbent workflows: current substitutes, switching costs, bundling
- Adoption catalysts: tech inflections, regulation changes, macro/behavior shifts
- Distribution reality: who sells, how bought, typical sales motion

## Where to Find Signals

### Primary / Auditable

- Government statistics (industry output, establishment counts, employment): see `references/source-hierarchy.md`
- Regulator datasets for regulated verticals (throughput, approvals, claims): example openFDA https://open.fda.gov/
- Public company filings for category economics and segment splits (10-K/10-Q): SEC EDGAR API docs https://www.sec.gov/edgar/sec-api-documentation

### Useful Supporting Sources

- Trade/standards bodies for taxonomy + installed base (ISO/IEC/IEEE/GS1 etc.)
- University library guides as maps to datasets (starting points, not citations):
  - Georgetown entrepreneurship data & market size guide: https://guides.library.georgetown.edu/c.php?g=810742&p=5785036

## How to Write the Insight Block

Use 5-10 bullets. Each bullet should be one of:

- Driver: "Spend grows when ___" (+ cite or explain)
- Constraint: "Adoption capped by ___" (+ cite or explain)
- Structure: "Market is fragmented; distribution runs through ___" (+ cite)
